# Gestión de Residuos Peligrosos

Sistema web para el registro, seguimiento y control de residuos peligrosos, la elaboración de reportes diarios y la gestión de riesgos relacionados con las actividades operativas.

## 📋 Funcionalidades principales

- **Dashboard:** resumen de registros, cantidades de residuos y niveles de riesgo.
- **Inventario de residuos:** registro por ubicación, clasificación, tipo de residuo, contenedor, cantidad, estado y peso.
- **Reportes diarios:** registro de actividades, responsables, residuos gestionados, incidencias y observaciones.
- **Matriz IPERC:** identificación de peligros, evaluación de riesgos y registro de medidas de control.
- **Documentos y fotos:** almacenamiento, clasificación, consulta y descarga de archivos.
- **Mejora continua:** módulo para el seguimiento de acciones de mejora.
- **Mapas y riesgos:** visualización geográfica y representación de información de riesgos.
- **Exportación y respaldo:** generación de informes en PDF, Word y Excel, exportación de información geográfica y respaldo de datos.

## 🖥️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage e IndexedDB para el almacenamiento local
- Leaflet para la funcionalidad cartográfica
- Google Fonts para la tipografía

La aplicación también contempla integración con servicios de base de datos y archivos cuando el entorno de ejecución los proporciona.

## 🚀 Instalación y ejecución

1. Descarga o copia el archivo HTML del proyecto.
2. Guárdalo en una carpeta de trabajo con el nombre `index.html`.
3. Abre el archivo en un navegador web actualizado, como Google Chrome o Microsoft Edge.
4. Ingresa al módulo correspondiente y comienza a registrar información.

**Importante:** la versión local guarda los datos en el navegador utilizado. Para evitar pérdidas, utiliza la opción de exportación y respaldo. Para trabajar con datos compartidos entre usuarios, se requiere configurar y verificar la integración con una base de datos.

## 📊 Uso del sistema

1. Registra los lotes de residuos en el inventario.
2. Elabora los reportes correspondientes a cada jornada.
3. Identifica los peligros y evalúa los riesgos mediante la matriz IPERC.
4. Adjunta fotografías y documentos de respaldo.
5. Registra y realiza seguimiento de las acciones de mejora.
6. Consulta los mapas y genera los informes necesarios.
7. Realiza respaldos periódicos de la información.

## 🔐 Consideraciones

- Los registros deben corresponder a información real y verificable.
- La clasificación y evaluación de riesgos deben ser revisadas por personal competente.
- Los respaldos deben conservarse en una ubicación segura.
- El sistema no sustituye la revisión de los requisitos legales y ambientales aplicables.
- Antes de utilizarlo en producción, deben verificarse la persistencia de datos, los permisos de acceso, la seguridad y la compatibilidad de las exportaciones.
